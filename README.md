# production-agent-observability

Stack de observabilidad para agentes en producción: tracing
(LangSmith/Arize), dashboards de latencia/costo, alertas por
bucles o fallos, canary y rollback.

**Qué demuestra:** operación confiable de agentes en producción.

## Checklist de features clave

- [ ] Tracing integrado (LangSmith / Arize u equivalente)
- [ ] Dashboards de latencia y costo
- [ ] Alertas ante bucles infinitos o fallos
- [ ] Despliegue canary
- [ ] Rollback ante regresiones
